# Brain Tumor Segmentation

Multimodal BraTS 2024 brain tumor segmentation project.

## Data

BraTS-2024-Complete: https://huggingface.co/datasets/Spirit-26/BraTS-2024-Complete

## Setup

```bash
git clone https://github.com/ProbablyItsSpirit/Brain_Tumor_Segmentation
cd Brain_Tumor_Segmentation
pip install -r requirements.txt
```
