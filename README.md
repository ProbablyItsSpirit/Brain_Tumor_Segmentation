# Multimodal Brain Tumor Segmentation using BraTS 2024

## Overview
This research implements and compares multiple deep learning architectures for brain tumor segmentation using the BraTS 2024 dataset collection. Analyze domain adaptation across tumor types
## Dataset

The complete organized BraTS 2024 dataset is available on Hugging Face:
[BraTS-2024-Complete](https://huggingface.co/datasets/Spirit-26/BraTS-2024-Complete)

Includes:
- BraTS-GLI: 1,809 glioma cases
- BraTS-MEN-RT: 571 meningioma cases  
- BraTS-PED: 348 pediatric cases
- Total: 2,728 multi-parametric MRI scans
